Docs tell a reader what the code is and how to use it, now.

Review doc comments, help text, README and other docs the diff adds or changes, one sentence at a time.

A finding is a sentence that:

- is false.
- describes history: what changed, what it used to do, or how it got there. Changelogs, release notes, migration
  guides and decision records exist to hold history, and are exempt, as are docs the repo rules say keep it.
